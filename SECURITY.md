# Security policy

This repository holds documents and release files of public data. It has no running service.

If you find a security or privacy problem, do not open a public issue. Send a message through the contact form at <https://pepbank.io/contact>. Choose the topic "General question" and start the message with "Security". Describe the problem and how to reproduce it. Do not send medical records or other private health details.

This policy covers this repository and the data in it. For a problem in the PepBank website, the API or the MCP server, use the same form.

To report a wrong value in the data, use the [data error form](https://github.com/pepbank/pepbank-data/issues/new?template=data-error.yml) instead.
